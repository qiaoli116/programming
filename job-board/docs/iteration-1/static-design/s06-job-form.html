Please describe the role.
  • One screen, two modes. UC-06 says the edit form is “the same form as UC-05, filled with the current values”. Only the heading, the button label and the starting values change.
  • Company is not typed: it comes from the employer's account and cannot be changed here, so an employer cannot post under another company's name.
  • Only salary is optional, matching the data model. The date posted is set by the system, so it is not on the form.
  • The form has no closing date and no “close listing” – both were deferred in Stage 1.
