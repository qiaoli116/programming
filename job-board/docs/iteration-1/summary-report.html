Iteration 1 – summary report

Job board, minimal prototype · all six stages complete · Friday 30 October 2026

In one paragraph

Iteration 1 built the smallest complete loop of a Seek-style job board: an employer posts a job, a job seeker finds it and applies, and the employer reads the application. It went through all six stages of the development process, from use cases to a signed-off test run. The final run passed all 43 items of the test plan. Two problems found in testing were written up as tickets, fixed and proved fixed by a later run. The prototype runs on local host only and has now reached the end of its life; the project moves on to iteration 2.

Neither problem was a missing requirement, so nothing went back to Stage 1. Both fixes were small and followed the signed-off design.

Lessons

What went well

  • Use cases became the test plan, then the tests: every use case has a test and every test traces back to a requirement.
  • Signed-off mockups gave the build a clear target, and the manual checklist showed where they fell short.
  • One command runs the whole plan and writes a dated result.
  • Findings were written as tickets with the cause, fix and proof, then closed by a later run.

What to change next time

  • Check mockups at phone width in Stage 2, not only on a desktop screen.
  • Decide in Stage 2 what "matches the mockup" means, to make the Stage 4 review quicker.
  • Keep screenshots out of routine results; save them only for failures and reviews (decision 32).
  • Commit at the end of each stage.
