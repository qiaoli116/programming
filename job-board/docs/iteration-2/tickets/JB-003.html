A score built from one checked criterion looks as certain as one built from five

1. Report

The overall match is the plain average of the criteria that could be checked; "Unknown" is left out (decision 39). When the AI can check only one criterion, the overall is that one criterion alone, so a job shows 0/10 or 10/10 from a single fact. The card does say "1 of 5 criteria could be checked.", but the big number looks just as sure as a score built from five criteria, and with Sort by match such a job can jump to the top or the bottom of the list.

This follows the signed-off rule, so it is not a code defect. It is a weakness of the rule that the live check made visible.

Done when: a score built from very few checked criteria is shown in a way that tells the seeker it is weak, or is not used for sorting; the agreed rule is changed in the decision log first, then the rules tests and the test plan are updated.

2. Investigation

QuestionAnswer
Where is the rule?server/src/scoring/rules.ts (the overall is computed in code, never by the AI), described in use case UC-11 and decision 39.
Which cases are affected?Any job where 4 or 5 of 5 criteria come back "Unknown" because the profile does not mention them. The live check showed it for at least one of the 20 jobs scored (the count was not recorded).
Why was it not caught by tests?The tests check that the average is computed correctly (for example TC-11 and the rules tests), which it is. They cannot say whether the rule is a good one.

3. Solution (proposed, not built)

Options, from smallest to largest. A decision is needed before any of them is built.

OptionChangeCost
A. Say it on the cardWhen fewer than 3 criteria were checked, show "Low confidence" next to the score (text, not only colour).Small: MatchBadge and one CSS rule. The rule is unchanged.
B. Keep it out of the sortJobs with fewer than 3 checked criteria are sorted last, like unscored jobs.Small: sortJobs. Changes UC-13.
C. Change the mathsPull the score toward the middle when few criteria are checked, or use weights (already listed as a future extension, Q3).Larger: changes the agreed rule, UC-11 and the rules tests.

Suggested: option A first. It keeps the simple rule that is easy to explain in class and removes the false certainty.
